# 開発のしかた

## 作品を書く Claude Code は、実データを開かない

- この作品のコードを書く Claude Code は、作者のふだんの設定とは別の設定のフォルダで起動している。
- その設定は次の3つを拒否する。
  - 読み取りの道具で、実データのフォルダ・試用の記録のフォルダ・学校の同期フォルダ・`.env` を読むこと
  - 実データのフォルダと試用の記録のフォルダに、書き込みの道具で書くこと
  - それらのパスや `.env` の名前を含むコマンド（Bash・PowerShell）
- 本物の設定はリポジトリの外にある。ここに置いた [claude-code-settings.example.json](claude-code-settings.example.json) は、場所を置き換えた写し。
  - `<EBINO_DATA_DIR>` は実データのフォルダ、`<EBINO_RECORDS_DIR>` は記録のフォルダ。作品はこの2つを環境変数から読む。
  - `<学校の同期フォルダ>` は、学校のファイルが同期されるフォルダ。
  - モデルは Opus で、effort は high。
- Claude Code は、架空の見本データ（`samples/`）とテストで作る。

## 実データでの実行は、別の Claude Code が受け持つ

- 実データでの実行は、作者の側の別の Claude Code が受け持つ。
- 作品を書く Claude Code に返すのは、件数と、中身を伏せた形（理由のコード・ID）だけ。
- 実データでだけ出る失敗は、この返ってきた形をもとに直す。

## 製品の中の係ごとのモデル

`ebino/gate.py` の `MODELS` と `EFFORT` のとおり。どの係でも、断られたときや失敗したときに別のモデルが代わりに答えることはない（決まった文を出す）。

| 係（コードの名前） | モデル | effort | 選んだ理由 |
|---|---|---|---|
| 取り込み係（`tagger`） | claude-haiku-5-5 | low | 片ごとに話題の札と語りの種類を付けて分けるだけで、文は書かせない。片の数が多い。 |
| 司書（`librarian`） | claude-sonnet-5-5 | medium | 問いに合う片を、道具（人・場所・話題で絞る）を何回か呼んで探しに行く。道具の使い方の判断は要るが、最後にどの片を使うかは司会が選ぶので、Opus までは使わない。 |
| 司会（`moderator`） | claude-sonnet-5-5 | medium | 何十人分もの言葉を横に読んで、どの席にどの順で話させるかを選び、割れたところに見出しを立てる。席に聞く札と最後の一言で片を選ぶのも、この係。直し31 で、「聞く」から吹き出しまでを10秒くらいにするため Opus・high から下げた（先生が下げてよいと決めた）。架空の席で3つの組み合わせを比べ、選ぶ席と言葉はほぼ同じで、Sonnet・medium は Opus・high の約3分の1の時間だった。 |
| ふりかえり（`reflection`） | claude-opus-5-5 | medium | 司会の仕事。その子の記録を丸ごと読み、材料を1つ指して問いを返し、方向の違う次の一手の案を並べる。 |
| 編集者（`editor`） | claude-sonnet-5-5 | low | 質問カードの言い換え案と、長いポスターの目的の見本の要約を書く。文を書く係なので Sonnet。書く文は短く、コードの照合を通ったものだけ残すので、effort は low。 |
| 収穫カード③（`subjects`） | claude-haiku-5-5 | low | 記録を札1つと項目の番号2つに分けるだけで、文は書かせない。 |
| コーチとオブザーバー（`coach`） | claude-opus-5-5 | medium | その子の記録を読み、答えを隠さない問いを60字以内で2つ書く。架空の記録で比べると、Sonnet は60字を超えたり記録にない言葉を「」で引いたりして、コードの照合で止まることが多かったので Opus。1ラウンドごとに呼ぶので、effort は medium。 |
| 話し言葉（`speaker`） | claude-haiku-5-5 | low | 円卓の吹き出しの言葉を、その人が話しているように、語尾・言い回し・一人称だけ直す。1回で全部の吹き出しをまとめて渡す。先生が決めた。書いた文は、名前・元の言葉に無い禁止の言葉・その吹き出しの元の言葉に無い数字や漢字・カタカナの言葉・元の言葉から落ちた言葉・長さをコードが確かめてから出し、当たれば元の言葉を出す（止めた理由は記録に残る）。 |
| 質問の係（`asker`） | claude-haiku-5-5 | low | 1対1の質問。取り込みのとき、ページだけの席のページを聞く軸に振り分ける（軸の名前だけを受け取り、文は受け取らない）。先生が「早いモデルでパパッと」と決めた。答えは先生の表とは別のモデルの表（`ask_pages_model.tsv`）に書き、先生の表に中身があればそちらが先。ランキングの段落から、その人向けの質問を1つ作る（`ask_ranking_model.tsv`）。質問は、元の段落に無い漢字・カタカナの言葉や数・禁止の言葉（段落にあっても）・名前・40字を超える・「？」で終わらない、のどれかに当たれば使わない。 |
| 聞き手（`listener`） | claude-haiku-5-5 | low | 帰る前に、ひとこと（直し38）。地図の下の人の言葉から、押せる短い部分（16字まで）を1回で選ぶ。問いの向き（反応・自分）は決まっていて、言い方だけを作る。先生が速いモデルと決めた。問いは「」の中が記録か生徒の言葉にそのままある・名前・禁止の言葉・誘いの形・「あなたは」の決めつけ・家庭とお金と体の言葉（`listener_avoid.txt`）・60字・「？」1つで終わる・問いの言葉（なぜ・どう・何）1つ、をコードが確かめ、当たれば向きごとの決まった問いを出す。 |
| 光ったところ（`light`） | claude-sonnet-5-5 | low | 帰る前に、ひとこと（直し38）の最後に1回。生徒が書いた言葉から1つ選び、6つの力の1つに結んで、なぜその力か・何を深めるとおもしろいかを1文ずつ書く。文を書く係なので Sonnet（先生が決めた）。引いた言葉が生徒の書いた言葉にそのまま無い・力の名前が文に無い・決めつけ・ほめ言葉・禁止の言葉などに当たれば、見本と同じ順でコードが選び、力ごとの決まった文（`hitokoto_forces.tsv`）を出す。直し40：生徒の言葉には、最初の問いのあとに「聞く」で出した問いのうち、割れ目の見出しそのままでないものも入る（見出しそのままは司会の言葉なので入れない。聞き手の問いの「」の照らしも同じ）。割れ目を押したあとに書き直した問いがあれば、コードが選ぶとき見本の5番目の前にその問いを引き、⑤の決まった文を出す。 |

生徒が押したあとに画面が答えを待つ呼び出しには、どれも待つ時間の上限があり、やり直さない（`timeout` と `max_retries=0`）。上限を超えたら、その係が「使えなかった」ときと同じ道に進む。

| 呼び出し | 上限 | 超えたとき |
|---|---|---|
| 司書の探し | 1回 30 秒、1回の探しで合わせて 45 秒（呼ぶのは2回まで。直し31） | その回は使えなかった（決まった文。問いは欄に残る） |
| 司会の席と言葉の選び | 60 秒 | 同上 |
| 最後の一言（司会の係） | 30 秒 | 何も出さない |
| 席に聞く（司会の係） | 30 秒（司書は上と同じ） | 決まった文（`model_unavailable.txt`） |
| ふりかえりの問い返し | 45 秒 | 決まった問い返し（`ask_back_fallback.txt`）、次の一手の案なし |
| コーチとオブザーバーの帯 | 30 秒 | 帯を出さない |
| 編集者のカードの裏 | 20 秒 | カードは作り、裏だけ空 |
| 収穫カード③ | 20 秒 | 手がかりの言葉の照合で選ぶ |
| 話し言葉 | 8 秒 | どの吹き出しも元の言葉のまま |
| 取り込みのページの振り分け（1人分を1回） | 30 秒 | その席はモデルの表に書かず、次の取り込みでまた頼む |
| 取り込みのランキングの質問（1人分を1回） | 30 秒 | 同上 |
| 1対1の質問の言い換え（「この人に聞く」1回に1回） | 8 秒 | どの質問も先生の質問のまま |
| 帰る前に、ひとこと：押せる短い部分（1回） | 8 秒 | どのカードも、まるごと押す形のまま |
| 帰る前に、ひとこと：聞き手の問い（1つに1回） | 8 秒 | その向きの決まった問い |
| 帰る前に、ひとこと：光ったところ（1回） | 15 秒 | 見本と同じ順でコードが選び、力ごとの決まった文 |

1対1でスライドのページを出すとき（直し43、`one_tidy.py`）は、出す前にコードだけでページの文を整える（モデルは使わない）。ページ番号だけ・日付だけ・飾りの記号だけの行を外し、ページの最初の1行が表題らしいとき（「。」が無い・15字以下・文の終わりの形でない・箇条書きでない。1行だけのページは外さない）その1行を外し、PDF の途中の折れをつなぎ、箇条書きを1つずつ1文にする。足すのは「。」だけ。整えて空になったページと、整えた文に名前が当たったページは出さない。まとめて240字（`ONE_CUT_CHARS`）を超えるときは文の終わりで切る。記録に残っている言葉そのものは変えない。記録には、整えた文・外した行の数・理由の記号を残す。話し言葉の係には、整えた文を元の言葉として渡す（外した表題は「落ちた言葉」にならない。整えた文に無い漢字・カタカナの言葉や数を足せば止まる）。止まったとき・時間切れ・話し言葉を切っているときは、整えた文を出す。実データでの数は `tools/count_one_tidy.py` で数える（言葉は出さない）。
